Closed Shadow Lab

A web component that mounts its control inside a closed shadow root (data-testid="secret-widget"). Playwright's built-in engines cannot pierce a closed root; the recorder captures an instrumented host-chain locator (Phase C2) and the runner replays it via the closed-shadow bridge. The internal accessible name is deliberately not persisted. The nested / mixed / identity-change cases are covered by npm run verify:closed-shadow.
