Scenario W — document.write popup

Opens a blank window and builds its whole document with document.write — how generated report, print and confirmation tabs are made, and the shape that broke Recorder capture. document.write on a loaded document triggers an implicit document.open(), which removes EVERY event listener registered on the Window, the Document and its nodes, while leaving the Window's own properties untouched. A window-scoped install flag therefore still read installed for a page that was listening to nothing.

The popup never commits a URL either (it stays about:blank), so popup identity resolution always spends its full budget on it — which is why instrumentation must not wait behind that budget.
