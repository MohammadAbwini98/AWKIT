Scenario I — Script/timer popup identity

Purpose: a popup opened by a page timer with no corresponding click or switchToPopup step (SRS-BAO-001 FR-C1.3). It must still receive one deterministic synthetic alias that is stable across runs and derived from identity, not arrival order.

The timer popup URL deliberately carries a secret-shaped query string and a fragment (?token=…&session=…#section-2). Neither may ever appear in a popup alias or in any diagnostic — only origin and pathname are identity-bearing.
