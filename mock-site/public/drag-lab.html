Drag & Drop Lab

Native HTML5 drag-and-drop (draggable + dragstart / dragover / drop / dragend). Drag a card between the columns; each drop moves the card and reports the move in data-testid="drag-result". The Recorder captures this as a single drag step (source + drop-target locators) and the runner replays it with source.dragTo(target). Covered by npm run verify:mock-site and npm run verify:recorder-competitive.
