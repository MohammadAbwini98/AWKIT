Nested Iframe Lab

A two-level frame nesting (main → #frame-outer → #frame-inner → leaf) for exercising LocatorContext.frameChain. A locator that captures only the innermost boundary — or none — cannot reach the leaf button; only the ordered outer→inner chain does. The cross-origin, duplicate-iframe, navigate-after-attach and identity-change cases are covered by npm run verify:frame-chain.
